Re-Report

Look up a NYC 311 service request or an address, see what actually happened, and re-file with the history attached.

Address: house number + street, no apartment or borough. Numbers as digits ("2 Avenue", not "Second Avenue"). Data comes from NYC Open Data and usually lags the 311 portal by about a day.

Privacy: this page stores nothing and sends nothing anywhere except the public NYC Open Data API at data.cityofnewyork.us. No cookies, no analytics, no accounts. This site does not file anything with 311 for you; you paste the text into the official portal yourself.

"Closed without visible action" is a heuristic based on the wording of the agency's resolution text (for example "not observed", "no violation", "unable to", "referred", "could not", "duplicate"). It is a flag to look closer, not a verdict. Source: 311 Service Requests dataset erm2-nwe9. Open source, MIT.
