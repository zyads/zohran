311 history lookup

Re-Report, with receipts.

Look up a 311 request or an address, see what the city actually did about it, and re-file with the whole history attached.

Try

Address: house number + street, no apartment or borough. Numbers as digits ("2 Avenue", not "Second Avenue"). Data comes from NYC Open Data and usually lags the 311 portal by about a day.

How this works

Data. Every lookup queries the public 311 Service Requests dataset (erm2-nwe9) on NYC Open Data directly from your browser. An SR number returns that request, then the last 50 requests at the same street address. An address is normalized the way 311 stores it (uppercase, abbreviations expanded, ordinals stripped, padded cross-street numbers tried too) and queried by exact match.

"Closed without visible action" is a heuristic based on the wording of the agency's resolution text (for example "not observed", "no violation", "unable to", "referred", "could not", "duplicate"). It is the same rule the Ghost Tracker uses. It is a flag to look closer, not a verdict.

The re-report text counts prior requests of the same complaint type at the address, lists their SR numbers and how they were closed, and asks the agency to treat the new request as a repeat rather than a duplicate. Edit it however you like before filing.

Filing. This site does not file anything with 311 for you. Copy the text into the description box on the official NYC311 portal, or read it to the 311 operator.

Privacy: this page stores nothing and sends nothing anywhere except the public NYC Open Data API at data.cityofnewyork.us. No cookies, no analytics, no accounts. This site does not file anything with 311 for you; you paste the text into the official portal yourself.
